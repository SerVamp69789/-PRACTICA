# Контроль посещаемости

Аналитическая консольная система для администрации колледжа. Собирает журнал по всем группам, считает процент пропусков и готовит сводки: отстающие, лишение стипендии, отчисление.

Данные берутся из `students.json` (те же студенты и отметки, что в «Практичка № 10 .py»). Старый скрипт печатает процент присутствия. Это приложение считает процент пропусков и раскладывает студентов по мерам.

## Правила

| Статус | Пропуски | Что делать |
| --- | --- | --- |
| норма | меньше 30% | мер нет |
| отстающий | от 30% до 40% | беседа куратора |
| лишение стипендии | от 40% до 50% | материалы на лишение стипендии |
| отчисление | 50% и выше | материалы на отчисление |

Процент группы и колледжа — это доля пропущенных занятий: сумма пропусков ÷ сумма занятий × 100. Отчёт на стипендию включает и тех, кого готовят к отчислению: при отчислении стипендия тоже не сохраняется.

## Меню

1. Список групп: численность, процент пропусков, сколько студентов на каждой мере.
2. Группа: список студентов, шкала пропусков, карточка с датами пропусков.
3. Сводный отчёт по колледжу.
4. Отстающие (пропуски от 30%).
5. Отчёт на лишение стипендии.
6. Отчёт на отчисление.
7. Сохранить эти отчёты в папку `reports/`.

## Запуск на компьютере

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python -m attendance
```

Без меню, сразу текст отчёта:

```bash
python -m attendance --report summary
python -m attendance --report lagging
python -m attendance --report scholarship
python -m attendance --report expulsion
python -m attendance --group 2ИП-2-25
python -m attendance --save
```

Файл журнала можно подменить: `python -m attendance --data путь/к/students.json`.

## Тесты

```bash
python -m pytest -q
```

## Docker

Образ сам прогоняет тесты во время сборки. Интерактивное меню требует `-it`.

```bash
docker build -t attendance .
docker run -it --rm attendance
docker run --rm attendance --report summary
docker run --rm attendance python -m pytest -q
```

Последняя команда не сработает как есть, потому что у контейнера точка входа — само приложение. Повторный прогон тестов:

```bash
docker run --rm --entrypoint python attendance -m pytest -q
```
