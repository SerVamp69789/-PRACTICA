# Система контроля посещаемости

Аналитическая консольная система для администрации колледжа. Она агрегирует журнал по всем группам, считает процент пропусков и формирует сводные административные отчёты, чтобы вовремя видеть отстающих и готовить материалы на лишение стипендии или отчисление.

Основной файл: `kontrol_poseshchaemosti.py`. Журнал собирается из `students.json` и `journal.xlsx`: одинаковые студент и дата считаются один раз.

## Что делает меню

На первом экране сразу список групп и процент пропусков по колледжу.

| Ввод | Результат |
| --- | --- |
| номер или код группы, например `1` или `2ИП-2-25` | список студентов этой группы, процент пропусков и карточка с датами |
| `сводка` | сводный административный отчёт по всем группам |
| `отстающие` | студенты, которых уже нужно заметить |
| `стипендия` | отчёт для лишения стипендии. Отчисление сюда тоже входит, потому что стипендию при нём снимают |
| `отчисление` | отчёт для отчисления. Тех, кого только лишают стипендии, здесь нет |
| `сохранить` | те же отчёты в папку `reports/` |
| `0` | выход |

## Правила

| Статус | Пропуски | Отчёт |
| --- | --- | --- |
| норма | меньше 30% | мер нет |
| отстающий | от 30% до 40% | список отстающих |
| лишение стипендии | от 40% до 50% | отчёт для лишения стипендии, без отчисления |
| отчисление | 50% и выше | отчёт для отчисления и, вместе с ним, лишение стипендии |

Лишение стипендии не означает отчисление. Отчисление означает и лишение стипендии.

Процент группы и колледжа — доля пропущенных занятий: сумма пропусков ÷ сумма занятий × 100.

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python kontrol_poseshchaemosti.py
```

Без меню:

```bash
python kontrol_poseshchaemosti.py --report summary
python kontrol_poseshchaemosti.py --report lagging
python kontrol_poseshchaemosti.py --report scholarship
python kontrol_poseshchaemosti.py --report expulsion
python kontrol_poseshchaemosti.py --group 2ИП-2-25
python kontrol_poseshchaemosti.py --save
```

Другой журнал: `python kontrol_poseshchaemosti.py --data путь/к/students.json`.

## Тесты

```bash
python -m pytest -q
```

## Docker

Образ прогоняет тесты при сборке. Меню запускается с `-it`.

```bash
docker build -t attendance .
docker run -it --rm attendance
docker run --rm attendance --report summary
```

Повторный прогон тестов в уже собранном образе:

```bash
docker run --rm --entrypoint python attendance -m pytest -q
```
